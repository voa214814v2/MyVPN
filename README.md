# Мой VPN

Маленький VPN-клиент для Android: одна кнопка, без аккаунтов и подписок.

- **WARP** — бесплатный туннель Cloudflare. Приложение само регистрирует
  устройство, генерирует ключи на телефоне и поднимает обычный WireGuard.
- **Конфиг** — можно вставить любой `.conf` от WireGuard или **AmneziaWG**
  (например, со своего VPS). AmneziaWG-конфиг с параметрами `Jc`, `Jmin`,
  `Jmax`, `S1`, `S2`, `H1`–`H4` проходит DPI там, где обычный WireGuard режут.

Собрано на `com.zaneschepke:amneziawg-android` — это официальный туннель
AmneziaWG для Android. Он понимает и обычный WireGuard (в том числе конфиг
WARP), и обфусцированный AmneziaWG, поэтому туннель настоящий, а не самописный.

## Вкладки

- **VPN** — большой ключ 🔑 вместо кнопки: нажатие подключает VPN и добавляет
  ключ в кликер. Рядом — счётчик, уровень и полоска прогресса, ниже — кнопка
  «Отключить». Состояние и скорость — в карточке сверху.
- **Темы** — 8 цветов акцента; меняют ключ, вкладки и заголовки инструкции,
  выбор сохраняется.
- **Логи** — все события с временем: обновить, скопировать, очистить.
- **Помощь** — короткие гайды по типичным ошибкам (403 от WARP, нет интернета,
  нет разрешения на VPN, как поднять свой сервер с AmneziaWG, как вставить
  конфиг) и строка версии с проверкой обновлений.

## Кликер

Каждое нажатие ключа даёт 1 ключ. 25 ключей = новый уровень (Новичок →
Любитель → Знаток → Мастер → Гуру → Легенда). Прогресс хранится на телефоне
и не сбрасывается между запусками. Когда VPN уже подключён, ключ просто
считает нажатия; отключает — отдельная кнопка.

## Обновления из приложения

При запуске приложение смотрит `version.json` в ветке `updates` и, если вышла
новая версия, показывает баннер «Обновление … — нажми». По нажатию APK
скачивается и открывается системный установщик: удалять старую версию и
заново искать файл не нужно. Подпись постоянная, поэтому обновление ставится
поверх.

Чтобы это работало, **репозиторий должен быть публичным**: `raw.githubusercontent.com`
не отдаёт файлы приватного репозитория без токена. Ветку `updates` workflow
создаёт и обновляет сам при каждом пуше в `main`.

## Как получить APK

Сборка идёт в GitHub Actions, на телефоне ничего компилировать не нужно.

1. Создай репозиторий на GitHub. Для автообновлений он должен быть **публичным**.
2. Загрузи в него все файлы проекта, сохраняя структуру папок.
3. Открой вкладку **Actions** → workflow **Build APK** → **Run workflow**.
4. Через ~3 минуты в разделе **Artifacts** будет `myvpn-debug-apk`.
   Внутри — `app-debug.apk`, его и ставим на телефон.
5. Ветка `updates` с `myvpn.apk` и `version.json` появится автоматически.

APK подписан постоянным ключом из `keystore/myvpn.keystore`, поэтому новые
сборки ставятся поверх старых без удаления. Если ставишь самую первую версию
поверх сборки, подписанной случайным отладочным ключом, один раз придётся
удалить приложение.

## Как пользоваться

1. Открой приложение → вкладка **VPN** → нажми на ключ 🔑.
2. Разреши создание VPN-подключения (системный запрос).
3. Ключик в статус-баре = туннель работает.

Кнопка **Конфиг** — вставить свой `.conf`:

```
[Interface]
PrivateKey = ...
Address = 10.8.0.2/32
DNS = 1.1.1.1

[Peer]
PublicKey = ...
AllowedIPs = 0.0.0.0/0
Endpoint = 1.2.3.4:51820
```

## Ограничения

- WARP бесплатный, но в России часто сам попадает под блокировки.
  Если после подключения YouTube не открывается — WARP не проходит,
  нужен свой сервер.
- Обычный WireGuard виден DPI. AmneziaWG это обходит, но только если конфиг
  действительно AmneziaWG: на сервере должен быть поднят AmneziaWG, а не
  обычный WireGuard.
- `debug`-сборка: Play Protect может ругаться на «неизвестный источник».
